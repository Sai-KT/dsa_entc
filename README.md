## ⚙️ Compilation & Execution Guidelines
All C programs are written in standard C (C99/C11 compliant) and can be compiled using GCC or Clang:

```bash
# Navigate to the specific practical directory
cd Practical-XX

# Compile the source file
gcc -Wall -Wextra practical-XX.c -o practical-XX

# Execute the binary
./practical-XX
```
